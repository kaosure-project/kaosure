# Task Management

โฟลเดอร์นี้ใช้จัดการสถานะงานของ Kao Ecosystem

## Purpose

ใช้ติดตามงานที่ต้องทำ งานที่กำลังดำเนินการ
งานที่ติดเงื่อนไข และงานที่เสร็จแล้ว

AI ต้องใช้ข้อมูลจากโฟลเดอร์นี้เพื่อทราบสถานะงานปัจจุบัน

---

## Task Status

### TODO

งานที่ยังไม่ได้เริ่ม

### DOING

งานที่กำลังดำเนินการ

### BLOCKED

งานที่ยังไม่สามารถดำเนินการต่อได้
เนื่องจากมีเงื่อนไขหรือ Dependency ที่ยังไม่พร้อม

### DONE

งานที่ดำเนินการเสร็จแล้ว

---

## Important Rule

งานที่ BLOCKED ห้ามถือว่า DONE

งานที่ยังไม่สมบูรณ์ต้องคงอยู่ในระบบ
จนกว่าจะได้รับการแก้ไขและยืนยันว่าเสร็จ

---

## Dependency

หากงานหนึ่งต้องรออีกงานหนึ่ง
ต้องระบุ Dependency ให้ชัดเจน

ตัวอย่าง:

Task A
Status: BLOCKED

Depends On:
Task B

Reason:
ต้องรอ Task B ก่อนจึงดำเนินการต่อได้

---

## Related Files

งานที่เกี่ยวข้องกับ Source Code
ควรระบุไฟล์หรือ Directory ที่เกี่ยวข้อง

ตัวอย่าง:

lib/features/kao_id/identity/

---

## AI Rule

เมื่อเริ่ม Session ใหม่
AI ควรตรวจสอบงานที่มีสถานะ:

- DOING
- BLOCKED

ก่อนเริ่มเสนอการทำงานใหม่

---

## Completion Rule

AI ห้ามเปลี่ยนสถานะเป็น DONE เอง

ต้องได้รับการยืนยันจากผู้บริหารว่า
งานเสร็จสมบูรณ์แล้ว

---

## Update Rule

เมื่อสถานะงานเปลี่ยน:

TODO → DOING
DOING → BLOCKED
DOING → DONE
BLOCKED → DOING

ต้องอัปเดตข้อมูลของ Task ให้เป็นปัจจุบัน

---
