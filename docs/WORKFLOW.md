# Development Flow

ทุก Feature ต้องผ่านลำดับนี้

Idea
↓
Research
↓
Business Rules
↓
Architecture Decision (ADR)
↓
Database Design
↓
API Design
↓
UI/UX Design
↓
Implementation
↓
Testing
↓
Documentation Update
↓
Code Review
↓
Done

---

# Rule

ห้ามข้ามขั้น

หาก Feature ไม่มี Business Rule

ห้ามเขียน Code

หาก Database ยังไม่พร้อม

ห้ามสร้าง API

หาก API ยังไม่พร้อม

ห้ามเชื่อม Flutter

---

# Definition of Done

Feature ถือว่าเสร็จเมื่อ

✓ Business Rule Complete

✓ ADR Complete (ถ้าจำเป็น)

✓ Database Complete

✓ API Complete

✓ UI Complete

✓ Testing Complete

✓ Documentation Updated

✓ Review Complete
