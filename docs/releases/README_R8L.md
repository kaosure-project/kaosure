# R8L — เพิ่ม 5 ภาษา หลัง R8C fix

เพิ่มญี่ปุ่น จีนตัวย่อ พม่า ลาว และเวียดนาม รวมกับไทยและอังกฤษเป็น 7 ภาษาที่เลือกได้
แปลข้อความครบ 512 key ต่อภาษา ตาม app_en.arb ของ R8C รวม Auth, โปรไฟล์, KYC, บัตร, หนังสือเดินทาง, ใบพำนัก, ธนาคาร, การตรวจเอกสารและข้อความผิดพลาด

## ติดตั้ง
ใช้กับโปรเจกต์ที่ติดตั้ง R8C fix แล้ว (ชุดเดิมผู้ใช้รันผ่าน 165 tests)

```powershell
$backupName = 'kaoid_before_R8L_' + (Get-Date -Format 'yyyyMMdd_HHmmss') + '.zip'
Compress-Archive -Path lib,test -DestinationPath $backupName
Expand-Archive -LiteralPath .\kaoid_languages_R8L.zip -DestinationPath . -Force
flutter gen-l10n
flutter analyze
flutter test test/localization/languages_r8l_test.dart
flutter test test/localization
```

ถ้าแอปเปิดอยู่ ให้กด R ใน Terminal ที่รันแอป เพื่อ hot restart หลังสร้างภาษา
เลือก การตั้งค่า → ภาษา แล้วเลือกชื่อภาษาตามตัวอักษรของภาษานั้น

| ภาษา | ตัวเลือก | ARB |
|---|---|---|
| ญี่ปุ่น | 日本語 | app_ja.arb |
| จีนตัวย่อ | 简体中文 | app_zh_Hans.arb |
| พม่า | မြန်မာ | app_my.arb |
| ลาว | ລາວ | app_lo.arb |
| เวียดนาม | Tiếng Việt | app_vi.arb |

app_zh.arb เป็นภาษา Chinese พื้นฐานสำหรับ fallback โดยใช้คำแปลจีนตัวย่อเดียวกัน ไม่ใช่ภาษาเพิ่มหรือจีนตัวเต็ม ต้องแก้สองไฟล์จีนให้ตรงกันเมื่อเพิ่มข้อความ

## สิ่งที่เปลี่ยน
- เพิ่มไฟล์ภาษา 6 ไฟล์ (5 ภาษา + Chinese fallback)
- เพิ่ม app_languages.dart เป็นรายชื่อภาษากลาง ใช้ชื่อเจ้าของภาษาเพื่อเปลี่ยนกลับได้ง่าย
- เปลี่ยน GeneralSettingsTile ให้เลือกครบ 7 ภาษาและแสดงชื่อภาษาปัจจุบันถูกต้อง
- ใช้ LocaleController และการบันทึกภาษาบนอุปกรณ์ของเดิม ไม่เปลี่ยน Auth/ฐานข้อมูล/กติกา KYC
- ไม่ทับ app_en.arb, app_th.arb, l10n.yaml หรือหน้าธนาคารที่แก้ R8C fix
- ไม่ส่งไฟล์ Dart ภาษาที่สร้างอัตโนมัติ ต้องรัน flutter gen-l10n

## ตรวจแล้ว / ยังไม่ตรวจ
ตรวจด้วยสคริปต์แล้ว: JSON อ่านได้, ไม่มี key ขาด/เกิน, ทุก key มีคำแปล, ไม่มีอักษรเสีย, ไม่มีภาษาไทยหลุดในไฟล์ใหม่, placeholders {percent}/{date} และ metadata ตรงต้นฉบับ
ชื่อผลิตภัณฑ์ KaoSure, Kao ID, Kao Code, KaoPay คงเดิม; Email ในภาษาเวียดนามเป็นคำที่ใช้ตามปกติ

เพิ่ม Flutter tests 11 รายการ: key/placeholder 5 ภาษา, สลับภาษาจากเมนูและเปิดปฏิทินที่ความกว้าง 320px 5 ภาษา, ตรวจ locale tags และ Chinese fallback 1 รายการ
ยังไม่ได้รัน Flutter ในสภาพแวดล้อมจัด ZIP; ชุดทดสอบสลับภาษาใช้ตัวแทน locale controller และไม่ได้ทดสอบ SharedPreferences จริงใหม่
ต้องรันคำสั่งข้างต้นบนเครื่องผู้ใช้ และทดลองเปลี่ยนภาษาแล้วปิดเปิดแอปเพื่อตรวจการจำค่าของระบบเดิม
คำแปลยังไม่ได้ผ่านผู้ตรวจเจ้าของภาษา จึงควรตรวจถ้อยคำและฟอนต์กับผู้ใช้ภาษานั้นก่อนเปิดวงกว้าง โดยเฉพาะข้อความยืนยันเอกสาร

## ตรวจหน้าจอจริง
- เปลี่ยนภาษาแล้วเปิดหน้าเข้าสู่ระบบ โปรไฟล์ บัตร หนังสือเดินทาง ใบพำนัก และธนาคาร
- ตรวจข้อความยาว ปุ่ม ฟอนต์ สระและวรรณยุกต์ โดยเฉพาะลาว/พม่าบน Chrome และมือถือ
- เปิดตัวเลือกวันที่ ตรวจภาษาเดือน/ปุ่ม
- ปิดเปิดแอปใหม่ ภาษาเลือกไว้ต้องคงอยู่; ตัวเลือกตามระบบใช้ภาษาของอุปกรณ์ที่รองรับ
- ข้อมูลที่ผู้ใช้กรอก ชื่อผู้ถือเอกสาร หมายเหตุเจ้าหน้าที่ และข้อความอีเมล/SMS ภายนอกไม่ถูกแปลโดย ARB นี้
- การเปลี่ยนภาษาไม่ได้เปลี่ยนประเทศที่รองรับ (ไทย) สกุลเงิน THB หรือข้อกำหนดเอกสาร
