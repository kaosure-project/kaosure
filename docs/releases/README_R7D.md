# Kao ID R7D — ต่อจาก R7C ที่ผ่าน 132 tests

## สิ่งที่แก้
- หน้าคิวและรายละเอียดตรวจบัตรซ่อนข้อมูลเมื่อบัญชีปัจจุบันไม่ตรงกับบัญชีที่เปิดหน้า
- หน้าดูภาพเอกสารซ่อนภาพเมื่อออกจากระบบ/เปลี่ยนบัญชี และตรวจบัญชีอีกครั้งก่อนส่งผลตรวจ
- แปลรหัสข้อผิดพลาดที่รู้จักเป็นไทย–อังกฤษ ไม่แสดงข้อความฐานข้อมูลดิบ
- รีเฟรชสิทธิ์เจ้าหน้าที่และ Kao ID เมื่อโหลดหน้ารวมอีกครั้ง
- ซ่อนเลข Kao ID เดิมระหว่างรีเฟรช ป้องกันแสดงสถานะเก่าขณะรอข้อมูล
- เก็บการแก้ชุดทดสอบอีเมล: เลื่อนเมนูเข้ากลางจอก่อนกด
- เพิ่ม widget tests 6 รายการ (ไทย/อังกฤษ)

## ติดตั้ง
ต้องติดตั้ง R7C แล้ว แตก ZIP ที่โฟลเดอร์โปรเจกต์ หลังสำรอง lib และ test

```powershell
flutter gen-l10n
flutter analyze
flutter test test/localization
```

รอบนี้ไม่มี SQL migration และไม่มีการแต่งตั้งเจ้าหน้าที่หรืออนุมัติเอกสารจริง
ตรวจความตรงกันของ ARB และชื่อข้อความแล้ว แต่ยังไม่ได้รัน Flutter analyze/tests ในสภาพแวดล้อมผู้จัดทำ ห้ามถือว่าชุดทดสอบใหม่ผ่านจนกว่าจะรันบนเครื่องพัฒนา

## งานจริงที่ต้องปิดแยกจากผลทดสอบ
1. ผู้ใช้ระบุบัญชีเจ้าหน้าที่ที่สมัครแล้ว แยกจากผู้ส่งบัตร ก่อนตรวจบัญชีและกำหนดสิทธิ์
2. ผู้ส่งเอกสารอัปโหลดสองด้าน ตรวจสถานะรอตรวจสอบ ออกจากหน้าแล้วเปิดรูปกลับมา
3. เจ้าหน้าที่เปิดสองภาพ ตรวจข้อมูล แล้วอนุมัติหรือปฏิเสธพร้อมเหตุผล
4. ผู้ส่งเอกสารกลับหน้ารวม ตรวจสถานะ หากอนุมัติแล้วขอออก Kao ID และตรวจว่าเปิดใหม่ได้เลขเดิม
5. ทดสอบบัญชีทั่วไปเข้าเส้นทางเจ้าหน้าที่ไม่ได้ และเจ้าหน้าที่ตรวจเอกสารตัวเองไม่ได้
6. เปลี่ยนอีเมล: เจ้าของบัญชีเปิดลิงก์ยืนยันและตรวจอีเมลใหม่/การเข้าสู่ระบบจริง เบอร์โทรยังค้าง OTP จริงตามงานเดิม

แพตช์นี้คงระบบอีเมล การอัปโหลดบัตร และ backend R7C เดิม ไม่มีการบังคับสถานะให้ผ่าน KYC และไม่ถือว่าเป็นการรับรองระบบพร้อมใช้งานจริงทุกส่วน หนังสือเดินทาง ใบพำนัก ธนาคาร และ Wallet ยังต้องตรวจเชื่อมระบบและทดสอบจริงทีละส่วน
