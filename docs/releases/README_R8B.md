# R8B — ส่งใบพำนักและติดตามคำขอ

ติดตั้งต่อจาก R8A + R8A fix ที่ผ่าน 146 tests ไม่เปลี่ยนหน้าหนังสือเดินทางที่แก้แล้ว

## เพิ่มอะไร
- ฟอร์มใบพำนักจริง: ชื่อ/นามสกุล รองรับชื่อเดียว ประเทศ/หน่วยงานผู้ออก เลขเอกสาร วันออก/หมดอายุ
- เลือกเอกสารแบบบัตรสองด้าน หรือแบบหน้าเดียว; ระบุได้เมื่อเอกสารไม่มีวันหมดอายุ โดยเจ้าหน้าที่ต้องตรวจความถูกต้องต่อ
- ใช้ตัวตรวจ JPEG/PNG และพื้นที่ส่วนตัวเดิม ไม่เก็บลิงก์สาธารณะ
- บันทึกเอกสาร รูป และคำขอพร้อมกัน; สถานะ pending_review และหน้ารวมแสดงสถานะจริง
- เมื่อคำตอบขาดหาย ส่งซ้ำด้วย document ID เดิมและตรวจไฟล์เดิม ป้องกันการสร้างคำขอซ้ำ
- เปิดกลับมาดูสถานะ รูป วันหมดอายุ และเหตุผลปฏิเสธ; ปิดฟอร์มเมื่อมีคำขอรอตรวจ
- ซ่อนข้อมูลและภาพเมื่อเปลี่ยนบัญชี ข้อผิดพลาดอยู่ในเนื้อหาหน้า ไม่ทับปุ่มส่งซ้ำ
- ข้อความไทย–อังกฤษและ 8 widget tests ใหม่; ปรับเทสต์เดิมที่เคยตรวจว่าปุ่มใบพำนักถูกปิด

## ผลตรวจ
ฐานข้อมูลติดตั้ง migration residence_submission_r8b แล้ว ไม่ต้องรัน SQL ซ้ำ
SQL regression ผ่าน: ขาดด้านหลังถูกปฏิเสธและไม่เหลือเอกสารครึ่งรายการ, แบบหน้าเดียว/บัตร, ชื่อเดียว/นามสกุลก่อนชื่อ, retry ไม่ซ้ำ, ปฏิเสธ payload เปลี่ยน, วันหมดอายุ, คำขอซ้อน, RLS ข้ามเจ้าของ
ข้อมูลทดสอบทั้งหมด rollback ไม่มีคำขอทดสอบค้าง และไม่ได้อนุมัติเอกสารจริง
anon เรียก RPC ไม่ได้; authenticated ผ่านการตรวจเจ้าของ/บัญชี/ไฟล์ก่อนบันทึก
ตรวจ ARB และ import แล้ว แต่ยังไม่ได้รัน Flutter analyze/tests ในสภาพแวดล้อมผู้จัดทำ

## ทดลองจริง
เข้า การยืนยันตัวตน → ข้อมูลเพิ่มเติม → ใบพำนัก
หากบัญชีมีคำขอรอตรวจอยู่แล้ว จะแสดงเหตุผลและไม่เปิดฟอร์ม ไม่ต้องลบคำขอเดิมเพื่อทดสอบ
ใช้บัญชีทดสอบที่ไม่มีคำขอค้าง กรอกข้อมูล เลือกรูปที่เหมาะกับชนิดเอกสาร ส่ง แล้วเปิดหน้าเดิมอีกครั้งเพื่อตรวจสถานะและเปิดภาพ

## ขอบเขตที่ยังค้าง
นี่คือการส่งและติดตามเอกสาร ไม่ใช่การอนุมัติอัตโนมัติหรือรับรองเอกสารทุกประเทศ และไม่ออก Kao ID จากใบพำนัก
คำขอทุกชนิดยังใช้เงื่อนไขเดิมหนึ่งรายการรอตรวจต่อคน; หากต้องแนบหลักฐานหลายชนิดในคำขอเดียว ต้องออกแบบแบบชุดเอกสารแยกต่อไป
Owner/Admin และคิวอนุมัติใบพำนักยังต้องพัฒนาตามแผน; R7C ตรวจบัตรไทยเท่านั้น
การต่ออายุเอกสาร/แจ้งเตือน, ไฟล์อัปโหลดค้างที่ยังไม่มีคำขอ, ลบข้อมูลตามระยะเวลาเก็บรักษา และการพิสูจน์ว่าเจ้าของบัญชีเป็นเจ้าของเอกสารยังเป็นงานที่ต้องปิดก่อนเปิด production
งานถัดไป: บัญชีธนาคาร โดยคงการอนุมัติแยกจากการเพิ่มบัญชี
