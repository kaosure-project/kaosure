# Decisions

โฟลเดอร์นี้ใช้เก็บการตัดสินใจที่ได้รับการอนุมัติแล้ว
ของ Kao Ecosystem

## Purpose

ใช้เป็น Source of Truth สำหรับการตัดสินใจสำคัญของโครงการ

## What Should Be Saved

บันทึกเฉพาะเรื่องที่มีผลต่อ:

- Business
- Architecture
- Database
- Security
- Development
- Product
- Workflow
- Kao Ecosystem

## Decision Status

### Proposed

AI เสนอแนวทางแล้ว
แต่ยังไม่ได้รับการอนุมัติ

### Approved

ผู้บริหารอนุมัติแล้ว
สามารถใช้เป็นแนวทางในการพัฒนาระบบได้

### Rejected

ข้อเสนอถูกปฏิเสธ
ห้ามนำไปใช้เป็นแนวทางปัจจุบัน

### Superseded

การตัดสินใจเดิมถูกแทนที่ด้วยการตัดสินใจใหม่

## Important Rule

AI ห้ามบันทึกข้อมูลเป็น Approved
จนกว่าจะได้รับการยืนยันจากผู้บริหาร

ตัวอย่างคำยืนยัน:

- อนุมัติ
- ตกลง
- เอาแบบนี้
- ใช้แนวทางนี้
- บันทึกเป็นมาตรฐาน

## Decision File

การตัดสินใจแต่ละเรื่องควรสร้างเป็นไฟล์แยกกัน

ตัวอย่าง:

2026-08-08-kao-id-root-platform.md

## Required Information

แต่ละ Decision ควรมี:

- Title
- Date
- Status
- Decision
- Reason
- Impact
- Related Files
- Related Systems

## Modification Rule

ห้ามแก้ไข Decision เดิมโดยลบประวัติ

หากมีการเปลี่ยนแปลงสำคัญ
ให้สร้าง Decision ใหม่และระบุว่า
