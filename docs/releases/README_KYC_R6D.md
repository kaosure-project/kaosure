# R6D — ภาษาในหน้ายืนยันเอกสาร

ติดตั้งหลัง R6C เท่านั้น สำรอง lib,test แล้วแตก ZIP ที่โฟลเดอร์โปรเจกต์

```powershell
flutter gen-l10n
flutter analyze
flutter test test/localization
```

ขอบเขต: บัตรประชาชน หนังสือเดินทาง ใบพำนัก ธนาคาร และวิดเจ็ตในหมวดยืนยันตัวตน ทั้งไทย–อังกฤษ
ไม่มีการแก้การตั้งค่าสมัครสมาชิก ฐานข้อมูล หรือ Auth trigger

การสมัครยังไม่ต้องยืนยันอีเมล/เบอร์ทันที งานยืนยันภายหลังและการทดสอบ SMS จริงยังค้างอยู่ตาม docs/KAOID_R6D_STATUS.md
ปัญหาสถานะอีเมลระหว่างหน้าเมนูกับหน้ารายละเอียดยังต้องแก้ที่นโยบาย/หลักฐานการยืนยัน ไม่ใช่เปลี่ยนมาเชื่อ Auth อย่างเดียว

ตรวจภาษาโดยเลือก English แล้วเปิดและเลื่อนจนสุดทุกหน้า รวมช่องข้อมูล วันที่ ปุ่ม ข้อความข้อผิดพลาด และสถานะต่าง ๆ จากนั้นสลับกลับไทย
ใบพำนักยังอัปโหลดไม่ได้ ปุ่มจะแสดงเป็นปิดใช้งาน บัตรประชาชนเลือกภาพได้แต่ยังไม่ได้ส่ง KYC จึงไม่ควรนับว่ากระบวนการเอกสารเสร็จ

ชุดนี้ตรวจไฟล์ คำแปล และโครงสร้างแบบ static แล้ว แต่ยังไม่ได้รัน Flutter/analyze/tests ในสภาพแวดล้อมผู้จัดทำ
