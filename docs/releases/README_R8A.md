# R8A — หนังสือเดินทาง: ส่งเอกสารและติดตามคำขอจริง

ติดตั้งต่อจาก R7D ได้ รวมการแยกชื่อหน้าบัตรไทยของ R7E ไว้แล้ว ไม่เปลี่ยนคำขอบัตรที่ส่งไปก่อนหน้า

ฐานข้อมูลติดตั้ง migration passport_submission_r8a แล้วในโปรเจกต์ที่ใช้งาน มี SQL แหล่งที่มาใน docs ไม่ต้องรัน SQL ซ้ำ

## ตรวจแล้ว
- SQL regression ผ่าน: บันทึกเอกสารพร้อมคำขอ, ส่งซ้ำรายการเดิม, ปฏิเสธข้อมูลเปลี่ยนตอน retry, กันคำขอซ้อน, ตรวจวันหมดอายุ, RLS กันคนอื่นอ่าน
- ข้อมูล SQL ทดสอบย้อนกลับทั้งหมด ไม่มีเอกสารทดสอบค้าง และไม่มีการอนุมัติจริง
- anon ไม่มีสิทธิ์เรียก submit; authenticated ต้องผ่านการตรวจเจ้าของ/บัญชี/ไฟล์อีกชั้น
- ARB ไทยอังกฤษและชื่อ getter ตรงกัน
- เพิ่ม widget tests 6 รายการสำหรับ passport และรวม 2 รายการ R7E; ยังไม่ได้รัน Flutter ที่นี่

## ทดลองจริง
บัญชีที่มีคำขอบัตรไทยค้างอยู่จะแสดงข้อความให้รอคำขอเดิม ไม่ควรลบหรือสร้างคำขอซ้อนเพื่อทดสอบ ใช้บัญชีทดสอบที่ไม่มีคำขอค้างเมื่อพร้อม
กรอกชื่อ/นามสกุลตามเอกสาร หรือเลือกชื่อเดียว → ประเทศ/หน่วยงานผู้ออก → เลขหนังสือเดินทาง → วันเกิด/วันออก/หมดอายุ → ภาพหน้าข้อมูล JPEG/PNG → ส่ง → รอตรวจ → ออกจากหน้าแล้วเปิดใหม่ → ดูรูป

## ขอบเขต
ชุดนี้ทำการส่งและติดตาม ไม่ได้ทำอนุมัติหนังสือเดินทางหรือออก Kao ID จากหนังสือเดินทาง: R7C ยังตรวจเฉพาะบัตรไทย ต้องต่อในงานสิทธิ์เจ้าหน้าที่ตามแผน
ใบพำนัก ธนาคาร และระบบแจ้งหมดอายุยังเป็นงานถัดไป ดู docs/KAOID_VERIFICATION_COMPLETION_PLAN.md
ไม่มี provider ตรวจเอกสารรัฐบาล/ธนาคาร, OCR หรือ liveness เพิ่มในชุดนี้ ประเทศผู้ออกเก็บเป็นข้อความตามเอกสาร ไม่ใช้ตัดสินสิทธิ์อัตโนมัติ

## Security advisor
