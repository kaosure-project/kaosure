# R7E — แบบฟอร์มบัตรประชาชน ต่อจาก R7D

แยกช่องชื่อและนามสกุลตามบัตร ตรวจช่องที่ขาดพร้อมแจ้งใต้ช่องและสรุปใกล้ปุ่มส่ง พร้อม Snackbar ทันทีเมื่อข้อมูลไม่ครบหรือส่งล้มเหลว แสดงข้อความขณะส่ง ภาษาไทยและอังกฤษครบ

คงสัญญาข้อมูลเดิม: รวมชื่อ + เว้นวรรค + นามสกุลลง full_name ไม่เปลี่ยนฐานข้อมูลหรือเอกสารเดิม รักษาการส่งซ้ำด้วย document ID เดิมเมื่อคำตอบจากเซิร์ฟเวอร์ขาดหาย

พบในโค้ดเดิมว่าการตรวจฟอร์มที่ไม่ผ่านจะแสดงข้อความหลังปุ่มส่ง อาจอยู่นอกจอ ยังไม่มีหลักฐานว่าการกดของผู้ใช้ติดช่องใดหรือมีข้อผิดพลาดฝั่งเซิร์ฟเวอร์ แพตช์นี้เพิ่มการตรวจและการแจ้งผล ไม่ถือว่าการอัปโหลดจริงสำเร็จแล้ว

ติดตั้งหลังสำรอง lib,test:
flutter gen-l10n
flutter analyze
flutter test test/localization

เพิ่ม 2 tests ไทย/อังกฤษสำหรับฟอร์มไม่ครบ พร้อมปรับชุดเดิมให้กรอกชื่อแยกและตรวจ full_name ที่ส่งออก ตรวจ ARB/reference แล้ว ยังไม่ได้รัน Flutter ที่นี่

หลังติดตั้ง restart แอป กรอกชื่อ นามสกุล เลขบัตร วันที่ออก/หมดอายุหรือบัตรตลอดชีพ เลือกสองภาพแล้วส่ง หากไม่ผ่าน ส่งเฉพาะข้อความผิดพลาดกลับมา ไม่ต้องแนบข้อมูลบัตรจริง
