# Decision Checklist

ก่อนเพิ่ม Feature ใหม่ ให้ตอบคำถาม

- [ ] มี Business Rule แล้วหรือยัง
- [ ] ต้องมี ADR หรือไม่
- [ ] Database รองรับหรือยัง
- [ ] API ต้องเปลี่ยนหรือไม่
- [ ] UI ต้องเพิ่มอะไร
- [ ] Security ได้รับผลกระทบหรือไม่
- [ ] Notification ต้องเพิ่มหรือไม่
- [ ] Audit Log ต้องบันทึกหรือไม่
- [ ] ต้องอัปเดตเอกสารอะไรบ้าง
